AI CV Builder (MCP)

An MCP-powered AI application that helps users create, improve, and analyze professional CV content while providing job-focused skill recommendations.

Project Overview

AI CV Builder is an AI-powered application built with Python and the Model Context Protocol (MCP). It provides structured AI tools for creating professional CVs, improving resume sections, analyzing job alignment, and recommending relevant skills for a target role.

MCP Tools

  • Build CV: Creates a professional CV from candidate information and a target job.
  • Improve Section: Rewrites CV sections using clear and recruiter-friendly language.
  • Job Match: Analyzes candidate skills against a target job.
  • Skill Recommendations: Suggests relevant skills for a selected career role.

Key Features

  • AI-assisted CV generation
  • Professional CV section improvement
  • Job-to-skill matching
  • Target-role skill recommendations
  • Model Context Protocol (MCP) tool integration
  • Structured input validation
  • Modular Python architecture
